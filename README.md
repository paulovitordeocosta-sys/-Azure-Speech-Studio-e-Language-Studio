# Análise de Sentimentos com Language Studio no Azure AI

## Descrição do Projeto
Este projeto foi desenvolvido como parte do desafio da **Digital Innovation One (DIO)**, com o objetivo de praticar e aprofundar o uso das ferramentas **Azure Speech Studio** e **Language Studio**, focando na análise de fala e linguagem natural.  

O trabalho consiste em criar um repositório organizado contendo anotações, insights e resultados obtidos durante a prática.  A analise foi feito em relação as avaliações do Hotel Clayton Hotel Dublin Airport mostrando como ele se comporta avaliando certos comentários.

---

## Objetivos de Aprendizagem
Ao final deste projeto, consegui:  
- Aplicar os conceitos aprendidos em um ambiente prático.  
- Documentar processos técnicos de forma clara e estruturada.  
- tilizar o GitHub como ferramenta para compartilhamento de documentação técnica.

## Etapas Realizadas

1. **Configuração do ambiente**  
   - Acesso ao [Language Studio](https://language.cognitive.azure.com/) e configuração inicial.  
   - Seleção do recurso de **Análise de Sentimentos**.  

2. **Execução da análise de sentimentos**  
   - Testes com frases positivas, negativas e neutras.  
   - Registro dos resultados e confiabilidade das predições.  

3. **Insights obtidos**  
   - O modelo consegue identificar nuances emocionais no texto.  
   - Frases ambíguas podem gerar resultados com confiança dividida.  
   - Excelente aplicabilidade para chatbots, análise de feedback de clientes e monitoramento de mídias sociais.
